# Выпуск обновлений

1. Обновить версию в приложении, установщике и README.
2. Дополнить CHANGELOG.md и файл заметок в `releases`.
3. Собрать программу и выполнить интеграционные проверки.
4. Собрать установщик и portable-архив.
5. Создать GitHub Release с тегом версии и описанием изменений.
6. Приложить установщик, portable-архив и SHA256SUMS.txt.

Workflow **Windows release** в Actions готовит сборку и черновик релиза.
Проверить файлы и описание, затем опубликовать черновик.
В приложении пока нет автоматического обновления.
