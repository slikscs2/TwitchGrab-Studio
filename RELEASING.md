# Выпуск обновлений

## Принцип

В Git хранятся исходники, инструкции, иллюстрации и история изменений.
Установщики и portable-архивы загружаются в GitHub Releases.
Новая версия не заменяет файл старой версии: у неё свой тег и собственное описание.
Последний опубликованный релиз доступен по ссылке `/releases/latest`.

## Перед выпуском

1. Обновить версию в Studio.cs, installer.iss, README.md и имени portable-архива.
2. Добавить раздел в CHANGELOG.md и `releases/vX.Y.Z.md`.
3. Проверить исходники: `python scripts/audit.py`.
4. Получить закреплённый движок через `scripts/get-engine.ps1`, собрать `build.ps1`.
5. Запустить `TwitchGrab-Studio.exe --self-test` и проверить `studio-test.txt`.
   Тесты создают только синтетические медиа; не публиковать их выходные файлы.
6. Собрать `installer.iss` через Inno Setup, затем `scripts/package.ps1`.
7. Проверить содержимое `dist/portable`: `python scripts/audit.py --payload dist/portable`.
   Внешний движок поступает из официального архива с закреплённой SHA256;
   личные конфиги, cookies и токены в него не добавляются.
8. Установить в изолированную тестовую папку и проверить запуск, проекты и удаление.
9. Просмотреть `git diff --cached --stat` и `git diff --cached`; не использовать
   `git add .` в общей рабочей папке с пользовательскими видео и секретами.
10. Автор коммита — публичный ник и GitHub noreply; личный email не публиковать.

## Публикация

Создать тег, совпадающий с версией, и GitHub Release с заметками из `releases`.
Прикрепить только:

- `TwitchGrab-Studio-Setup-vX.Y.exe`;
- `TwitchGrab-Studio-Portable-vX.Y.zip`;
- `SHA256SUMS.txt`.

Запуск workflow **Windows release** из Actions собирает и проверяет проект,
после чего создаёт черновик релиза с файлами. Он использует временный встроенный
токен GitHub Actions, не личный API-ключ. Проверить черновик и опубликовать его.
Если релиз с таким тегом уже существует, workflow останавливается вместо перезаписи.

После публикации проверить страницу Releases, имена файлов и SHA256 скачанного установщика.
Для следующих обновлений в этом проекте сохранять тот же формат выпуска и ссылки автора.
В приложение пока не встроена автоматическая проверка обновлений.
